# Roadmap (see PLAN.md for the actionable checklist)

- **Wk 1–2 Foundation** → M1 Alpha: auth + schema + shell.
- **Wk 3–5 Core content**: destinations, search, detail; CRUD + storage.
- **Wk 6–8 Core value** → M2 Beta: maps, audio, offline bundles, itineraries.
- **Wk 9–10 AR pilot** (stretch): one museum exhibit, native ARCore, fallback.
- **Wk 11–12 Ship** → M3 MVP RC: integration, rules hardening, QA, demo.

Three monthly milestones (M1/M2/M3) map to the deliverables in the Gantt chart.
